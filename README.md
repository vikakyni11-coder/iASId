# iASId

Совершенно бесполезный, но удивительно хорошо документированный набор утилит.
Ничего серьёзного здесь нет и не планируется. Это репозиторий-заглушка,
который притворяется настоящим проектом.

## Возможности

| Команда      | Что делает                                                          |
|--------------|---------------------------------------------------------------------|
| `excuse`     | генерирует отмазки: случайные, по контексту или "отмазку дня"        |
| `cipher`     | шифрует текст: Цезарь, пьяный Цезарь, rot13, atbash, Виженер, аффинный |
| `random`     | кубики, монетки, пароли, взвешенные выборы, uuid                     |
| `ascii`      | баннеры, таблицы, прогресс-бары                                       |
| `horoscope`  | гороскоп на день, совместимость знаков, случайное предсказание        |
| `quote`      | мотивационные цитаты сомнительного качества                           |
| `timer`      | таймер, который помогает прикидываться занятым                        |

## Установка

```bash
pip install -e .
# или просто положить папку рядом с кодом — пакет self-contained
```

## Использование

```bash
python main.py excuse --today
python main.py excuse --context работа --count 3
python main.py cipher "я всё сломал" --algo drunk
python main.py cipher "секрет" --algo vigenere --key пароль
python main.py random --dice 2 --sides 20
python main.py random --password 24
python main.py ascii "ПРИВЕТ" --bar 73
python main.py horoscope овен --compat телец
python main.py quote
python main.py timer --minutes 1 --quiet
```

## Структура проекта

```
.
├── main.py                 # точка входа CLI
├── iasid/                  # основной пакет
│   ├── cli.py              # парсер аргументов и диспетчер подкоманд
│   ├── excuses.py          # генератор отмазок
│   ├── cipher.py           # шифры
│   ├── randomizer.py       # случайности
│   ├── words.py            # слова, пиг-латынь, марковская бессмыслица
│   ├── ascii.py            # ascii-арт, таблицы, прогресс-бары
│   ├── timer.py            # таймер прокрастинации
│   ├── motivation.py       # цитаты и постеры
│   ├── astrology.py        # гороскопы
│   ├── log.py              # логгер с цветами
│   └── utils.py            # вспомогательные функции
├── tests/                  # юнит-тесты
├── examples/demo.py        # демо всех модулей
├── fizzbuzz.py             # fizzbuzz со случайными багами
└── config.json             # конфигурация приложения
```
